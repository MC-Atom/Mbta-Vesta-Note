This is a quick repository to link the MBTA system to Vestaboard Notes

# Getting Started

You'll want to clone the repo then make two files in the main directory

`mbtaKey.txt` should include your mbta api key. Make one here! [https://api-v3.mbta.com/portal]
`vestaboardaKey.txt` should include your vestaboard api key. Find a tutorial for that here! [https://docs.vestaboard.com/docs/read-write-api/authentication]

Then change the configs in run main.py and run it for as long as you want!
